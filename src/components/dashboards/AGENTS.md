- Dashboards live under /dashboards (hub tiles + portco/events/network leaves; /dashboard redirects to /dashboards/portco). Charts reuse existing read functions and pure helpers (portco-ownership, events-dashboard) and show "unavailable" instead of demo data — counts stay real and testable.
- Network dashboard stats come from pure src/lib/network-dashboard.ts over existing reads (contacts, targets, Rating History, Email Activity, campaigns/members via fetchNetworkDashboard); touches dedupe per person per day per acting teammate (unattributed rows merge into an attributed same-day touch); outreach credits the actor, level changes the contact owner — counts match across sources and stay testable.
- Charts built with V.I.C. are ChartSpecs over the whitelisted datasets in src/lib/dashboard-charts.ts (validated server- and client-side) computed in the browser from real rows; saved specs live in the shared Cloud dashboard_charts table (team read, owner delete) — V.I.C. never writes code or data.
- On the PortCo ownership log view, tiny values group into shaded bands instead of squashing the axis: companies under $2M invested sit in the left "Under $2M" column and companies under 1% ownership in the bottom "Under 1%" row (both from src/lib/portco-ownership.ts, exact-threshold values stay on the axis; linear view keeps everyone on one axis) — the main plot always spans the real spread.
- Chart circles paint largest first with the selected company last (paintOrder); filtered-out circles are passive (no clicks) so they never cover or steal clicks from matching companies.
