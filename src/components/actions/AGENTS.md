# Actions components

- WorkstreamTrail ("Recent activity" in My Actions) is a read-only view over harvested activities and workstream links via src/lib/workstream-trail.ts; it never writes, so it cannot diverge from the activity store.
- My Actions PortCo/Network filing is the pure fileFollowUp helper (src/lib/action-grouping.ts) plus an optional saved "filing" in the follow-up edit overlay, so PortCo tags are never conflated with the person's company.
- Follow-up completion in My Actions is one click and optimistic: the item leaves the list and the detail pane shows Completed with Undo plus a "What's next?" box (optional note + quick-date follow-up via scheduleNextStepFn, then Next action); the save retries thrown errors with backoff (src/lib/follow-up-completion.ts withRetry). Scheduled follow-ups chain to the completed one (recordId = its id) so Before/Next (src/lib/action-thread.ts) and the workstream carry forward at read time without extra writes. Note-logged completions via completeActionFn close the follow-up themselves; caches are patched in place, not refetched — avoids Sheets quota bursts.
- The follow-up company field is the CompanyPicker over PortCos + Partners (src/lib/company-picker.ts, space/case-insensitive), saving the listed exact name; changing the company resets filing to automatic, and a forced PortCo filing without a PortCo falls back to automatic — so retagging to a partner never strands it in PortDev Ops.
- Action with V.I.C. resolves people against the source first: workstream (and follow-ups under one) pass focusCompany + Dell stakeholders; the pure src/lib/action-context-people.ts links stakeholders by exact name/email and PortCo contacts (never all of Dell), feeds them to the prompt, resolves first names/roles/"the stakeholders" against them before the full directory, and shows them as one-click recipients — proposals still need confirmation.
- My Actions list/detail split is a draggable divider whose layout is remembered per device in localStorage (read after hydration), and the split fills the window height so each pane scrolls on its own; the follow-up editor opens on demand (Edit) to keep the detail on one screen.
